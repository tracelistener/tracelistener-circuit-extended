Before you start

  • Back up your Circuit pack in Novation Components.
  • Close Components, DAWs, and other MIDI software.
  • Connect the original Circuit directly by USB.
  • Power on while holding Scales + Note + Velocity.
  • Use Chrome or Edge.

Optional — MIDI CC numbers Experimental

Choose the CC numbers the synth macros and drum knobs send and respond to, so they can control other gear. Leave them as they are to install the selected firmware unchanged.

Change CC numbers
Synth macros — Synth 1 and 2
Drum knobs — drum channel

Use 1–119, except 6, 32, 38 and 98–101. The new number is used for MIDI out and MIDI in. If another Circuit parameter on the same channel already uses it, the two swap, and a note under the field says which parameter moves where. The knobs still control the Circuit’s own sound too. On performance v2, synth CC 1 is reserved for the mod-wheel source.

The Korg NTS-1 preset was tested on the previous v0.5.0 build. The performance-v2 combination is checked in emulation; hardware testing is still needed. To undo, upload again with stock numbers.
